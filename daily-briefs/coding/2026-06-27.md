**v2 주요 변경 사항**
- Streamable HTTP가 권장 프로덕션 transport로 공식 전환
- `Mcp-Method` + `Mcp-Name` 헤더 필수 추가 → load balancer/gateway 라우팅 가능
- `stateless_http=True` + `json_response=True` 조합이 확장성 최적 설정
- v1 사용자는 `mcp>=1.27,<2` 버전 고정 권장 (stable 출시 전까지)

**Jayden 스택 적용**
- 현재 MCP 서버 운영 중이라면 **6/30 beta 전에** 버전 상한 추가 필수
- Streamable HTTP 전환 시 Supabase edge function과 연동 구조 재검토 필요
- `fastmcp` 사용 중이라면 별도 migration guide 존재 (PrefectHQ/fastmcp)
