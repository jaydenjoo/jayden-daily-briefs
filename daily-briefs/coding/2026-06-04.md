## ℹ️ 오늘의 맥락 보완 (1차 출처 직접 확인)

### Anthropic 공식 블로그 — Dynamic Workflows (2026-06-02)

**URL:** https://claude.com/blog/a-harness-for-every-task-dynamic-workflows-in-claude-code

Claude Code가 JavaScript 파일을 직접 작성해 subagent를 조율하는 dynamic workflow 기능 공개. 각 subagent는 독립 context window를 가지며, 어떤 모델·worktree 설정을 사용할지도 Claude가 결정. 핵심 harness 패턴 6가지:

1. **Classify-and-act** — 작업 유형 분류 후 전용 에이전트로 라우팅
2. **Fan-out-and-synthesize** — 병렬 subagent 실행 후 결과 병합
3. **Adversarial verification** — 별도 에이전트가 결과를 루브릭 기준으로 검증
4. **Generate-and-filter** — 다수 아이디어 생성 후 품질 기준으로 필터링
5. **Tournament** — 동일 작업에 경쟁 에이전트 투입
6. **Loop until done** — 종료 조건 충족까지 반복 subagent 실행

이 패턴들은 장기 단일 context 작업에서 발생하는 agentic laziness, self-preferential bias, goal drift를 방지하기 위해 설계됐다.
