## 🧠 CAT 6 — Context Engineering

### 🔔 Anthropic 공식: Managed Agents Memory (Public Beta)
**출처:** https://claude.com/blog/claude-managed-agents-memory  
**발표일:** 2026-04-23

**무엇인가:** Claude Managed Agents에 세션 간 지속 메모리를 제공하는 파일시스템 기반 persistent memory layer. 메모리는 workspace-scoped text 파일로 저장되며 agent가 표준 파일 도구로 읽기·쓰기. 모든 쓰기는 immutable versioned 레코드로 저장(감사 추적+롤백 가능).

**주요 스펙:**
- 메모리 store당 개별 파일 최대 100 kB (~25k tokens)
- 세션당 최대 8개 memory store 연결
- Python/TypeScript SDK: `managed-agents-2026-04-01` beta 헤더 자동 설정
- API 또는 Claude Console에서 직접 편집·내보내기 가능

**Code with Claude 2026(5/6)에서 추가 발표된 Dreaming 기능:** 이전 세션 내용을 agent가 자발적으로 recall하여 작업에 반영하는 기능. Managed Agents Memory의 상위 레이어로 동작.

**Jayden 적용점:** n8n + Claude API 워크플로우에서 "지난 번 PG-System 설정 어떻게 했었지?"를 Claude가 스스로 기억하는 구조. Memory store를 Supabase 프로젝트별로 분리하면 컨텍스트 혼선 방지 가능.
