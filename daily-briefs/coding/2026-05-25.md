### 카테고리 1 · Claude Code / Agentic SDK 패턴

**[coleam00/claude-memory-compiler](https://github.com/coleam00/claude-memory-compiler)** ⭐ ~850

Claude Code에 자동 진화하는 메모리를 부여한다. hooks가 세션을 자동 캡처하고, Claude Agent SDK가 핵심 결정·교훈을 추출하며, LLM compiler가 이를 구조화된 지식 아티클로 정리한다. Karpathy LLM Knowledge Base 아키텍처에서 영감을 받은 설계.

**검증:**
- ✅ 활성도: 최근 PR 및 activity 확인
- ✅ 신뢰도: Cole Medin 작성 (YouTube 10만+ 구독자 검증 채널), ~850 stars
- ✅ 문서화: AGENTS.md에 전체 기술 레퍼런스, `.claude/` 폴더 구조 포함
- ✅ 재현성: SessionEnd / PreCompact hook + `flush.py` 스크립트로 설치 가능
- ✅ 신규성: 인덱스 미보고

**작동 구조:**
1. `SessionEnd` / `PreCompact` hook → `flush.py` 실행 → 대화 추출
2. Claude Agent SDK `async streaming query()` → 핵심 결정·교훈 분류
3. `concepts/` + `connections/` 폴더에 cross-reference 지식 아티클 자동 생성
4. 다음 세션 `SessionStart` 시 관련 아티클 자동 주입

**Jayden 적용 가능성:** `CLAUDE.md`에 자동 누적 메모리. Next.js + Supabase 프로젝트에서 RLS 정책, API 설계 결정, n8n 워크플로우 패턴 등을 cross-session 기억. 비개발자도 설치 스크립트 한 번으로 구성 가능.

## 에코시스템 뉴스

### Anthropic, Stainless 인수 (2026-05-18)

모든 공식 Claude API 라이브러리를 자동 생성해온 SDK generator 회사 Stainless를 Anthropic이 인수했다. Stainless는 API spec에서 TypeScript, Python, Go, Java 등 SDK, CLI, MCP server를 자동 생성하는 회사로, 수백 개 회사가 활용해왔다. 인수 후 Stainless의 외부용 hosted SDK generator 서비스는 종료되며, 팀은 Claude Platform 내 에이전트-API 연결 강화에 집중한다. MCP 생태계 SDK 지원 속도가 장기적으로 빨라질 것으로 예상.

출처: [Anthropic 공식 블로그](https://www.anthropic.com/news/anthropic-acquires-stainless)
