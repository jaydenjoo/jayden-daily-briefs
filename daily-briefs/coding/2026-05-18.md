**핵심 내용:**

- `ClaudeSDKClient`: 양방향 인터랙티브 대화 (멀티턴)
- **`@tool` 데코레이터**: Python 함수를 인-프로세스 MCP 서버로 등록 (외부 subprocess 없음 → 성능↑)
- hooks 시스템: PreToolUse / PostToolUse 인터셉트 가능
- `allowed_tools` / `disallowed_tools`로 세분화된 권한 제어

```python
@tool("fetch_supabase", "Query table", {"table": str, "limit": int})
async def fetch_data(args):
    return {"content": [{"type": "text", "text": f"Row count: {args['limit']}"}]}

options = ClaudeAgentOptions(mcp_servers={"db": create_sdk_mcp_server("db", "1.0", [fetch_data])})
```

**참고:** MCP TypeScript SDK도 2026-05-17 업데이트 (CVE-2026-0621 ReDoS 취약점 패치 포함).

**Jayden 적용:**
n8n 대신 Python으로 Supabase → Claude 에이전트 파이프라인 구축 가능. `@tool` 하나로 Supabase 쿼리를 에이전트 도구로 등록 → 코드 최소화. Claude API 직접 사용 중이므로 마이그레이션 부담 최소.
