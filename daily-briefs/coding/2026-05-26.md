- **검증**: ✅ 활성도 · ✅ 신뢰도(Cloudflare 공식) · ✅ 문서화 · ✅ 재현성 · ✅ 신규성
- **포함 MCP 서버** (14개):

  | 서버 | 용도 |
  |------|------|
  | Observability | 로그·분석 쿼리 |
  | AI Gateway | 프롬프트 로그·응답 분석 |
  | Browser Rendering | 페이지→마크다운, 스크린샷 |

  | DNS Analytics | DNS 최적화 |
  | Audit Logs | 감사 로그 쿼리 |

- **설정** (로컬 설치 불필요):
  ```json

      "cloudflare-observability": {
        "command": "npx",

    }
  }
  ```

### 6. Context Engineering

#### codegraph `colbymchenry/codegraph`
> 코드베이스를 SQLite 지식 그래프로 사전 인덱싱해 Claude Code · Codex · Cursor의 불필요한 파일 스캔과 토큰 낭비를 제거

- **출처**: https://github.com/colbymchenry/codegraph
- **Star**: 24,870 | **최근 커밋**: 2026-05-24 (v0.9.4 릴리즈), 오픈 이슈 79개, PR 93개
- **검증**: ✅ 활성도 · ✅ 신뢰도 · ✅ 문서화 · ✅ 재현성 · ✅ 신규성
- **작동 방식**:
  1. tree-sitter AST 파싱으로 함수·클래스·의존성 추출
  2. SQLite FTS5로 전체 텍스트 검색 인덱스 생성
  3. OS 파일 이벤트(FSEvents/inotify/ReadDirectoryChanges)로 변경 시 자동 재동기화
  - 19개+ 언어, 14개 웹 프레임워크 지원
- **Jayden 적용**: 대형 Next.js 프로젝트에서 Claude Code가 전체 파일을 순차 스캔하는 대신 codegraph 쿼리로 "이 API 라우트의 호출 경로"를 즉시 반환 → 컨텍스트 윈도우 절약 + 응답 속도 개선. Supabase Edge Functions와 Next.js API 라우트 간 의존성 파악에 특히 유용
- **사용법**:
  ```bash
  # macOS/Linux
  curl -fsSL https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.sh | sh
  cd your-nextjs-project
  codegraph init -i   # 프로젝트 초기 인덱싱
  ```
