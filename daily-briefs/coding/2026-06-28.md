#### 1. `disler/claude-code-hooks-mastery` ⭐ 3.8k

**URL:** https://github.com/disler/claude-code-hooks-mastery
**활성도 주의:** commit 수 10개, 마지막 날짜 미확인 → 검증 조건부 포함

**핵심 주장:** Claude Code의 13개 hook lifecycle 이벤트를 모두 Python으로 구현한 레퍼런스 구현체.

**구현된 hook 전체 목록:**
| Hook | 역할 |
|---|---|
| UserPromptSubmit | 프롬프트 검증 · 컨텍스트 주입 |
| PreToolUse | 보안 차단 (1차 방어선) |
| PostToolUse | 실행 로그 · 트랜스크립트 변환 |
| PostToolUseFailure | 에러 로깅 |
| Notification | TTS 알림 |
| Stop | 완료 메시지 |
| SubagentStop / SubagentStart | subagent 생명주기 추적 |
| PreCompact | 컨텍스트 압축 전 트랜스크립트 백업 |
| SessionStart | 개발 컨텍스트 사전 로딩 |
| SessionEnd | 세션 정리 |
| PermissionRequest | 권한 감사 |
| Setup | 레포지토리 초기화 |

**빠른 시작:**
```bash
# Astral UV + Claude Code 설치 후
# .claude/settings.json → hooks 섹션 확인
# logs/ 폴더에서 JSON 실행 로그 확인
```

**Jayden 스택 적용:**
- `PreToolUse` hook으로 PayLoom/PG-System 관련 경로에 파일 접근 차단 규칙 추가 가능

- 번들 CLI — Claude Code 별도 설치 불요 (SDK에 포함)

**제공 예시 파일:**
- `examples/quick_start.py` — 기본 query() 인터페이스
- `examples/hooks.py` — hook 구현 패턴
- `examples/mcp_calculator.py` — in-process 도구 정의 end-to-end
- `examples/streaming_mode.py` — 양방향 대화 클라이언트

```python
import anyio
from claude_agent_sdk import query

async def main():
    async for message in query(prompt="Next.js 컴포넌트 작성해줘"):
        print(message)

anyio.run(main)
```

#### 6. `coleam00/context-engineering-intro` ⭐ 13.5k

**URL:** https://github.com/coleam00/context-engineering-intro
**활성도:** 날짜 미확인, 13.5k star 기준 활성 추정

**핵심 주장:** "AI 실패의 대부분은 모델 한계가 아닌 컨텍스트 부족" — PRP 패턴으로 해결.

**PRP (Product Requirements Prompt) 개념:**
```
PRD (요구사항) + 구현 단계 (HOW) + 검증 루프 (테스트 게이트) = PRP
```

**워크플로우 6단계:**
```bash
1. 레포 클론 + 템플릿 복사
2. CLAUDE.md에 프로젝트 규칙 설정
3. examples/ 폴더에 코드 패턴 추가
4. INITIAL.md에 기능 요청 작성 (PRP 형식)
5. /generate-prp → 구현 계획 생성
6. /execute-prp → 실행
```

**왜 작동하는가:**
- 검증 루프: AI가 자체 테스트로 오류 수정 (인간 개입 최소화)
- 코드 예시: AI가 프로젝트 패턴을 학습 → 일관성 향상
- 단계별 분리: 설계(generate)와 실행(execute) 분리

**Jayden 스택 적용:**
- INITIAL.md에 Supabase 스키마 변경 요청을 PRP 형식으로 작성 → 비개발자도 AI에게 정확한 지시 가능
- 기존 CLAUDE.md 고도화에 이 레포의 CLAUDE.md 템플릿 참조
