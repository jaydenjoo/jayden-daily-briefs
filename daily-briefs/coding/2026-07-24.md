- **저장소**: https://github.com/finna/Finn-loop
- **Star**: 161 | **최근 커밋**: 2026-07-23 (생성일 2026-07-22) | **저자**: finna
- **설명**: `finn-spec` → `finn-build` → `finn-review` 3개 스킬로 아이디어를 Linear 이슈, 구현+PR, 자동 리뷰 판정까지 연결하는 오케스트레이션 파이프라인. 머지 권한은 항상 사람에게 남긴다.

- **Jayden 적용성**: spec/build/review 역할을 서브에이전트·스킬로 분리하고 사람 승인 게이트를 강제하는 재사용 가능한 워크플로우 템플릿. n8n 오케스트레이션 설계에도 참고 가능.

**검증 관련 유의사항**: 위 3건 모두 README의 설치·사용법을 WebFetch로 정독해 재현 가능성을 판단했으며, 이번 세션에서 직접 클론·실행까지 하지는 않았다. "재현 가능"은 "문서가 구체적이고 그럴듯함"을 의미하지, "독립 실행 확인"을 의미하지 않는다.
