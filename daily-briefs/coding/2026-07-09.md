- **Jayden 적용**: 비개발자 관점에서 "재사용 가능한 워크플로우"를 바로 설치형으로 가져올 수 있는 사례. n8n/Supabase 관련 도메인 subagent가 있는지 목록만 확인 후 필요한 것만 선택 설치 권장(전체 설치는 컨텍스트 낭비).

### [Context Engineering] yvgude/lean-ctx
- **링크**: https://github.com/yvgude/lean-ctx
- **검증**: ★3.2k · 최근 릴리스 v3.9.3(2026-07-08, 어제) · 229개 릴리스로 활발한 개발 이력 · README에 설치 커맨드 명시 · 신규(미보고)
- **내용**: AI 에이전트가 "무엇을 읽고 기억하고 건드리는지" 로컬 Rust 바이너리 하나로 통제하는 컨텍스트 관리 레이어. MCP 도구 81개, 30개 이상의 코딩 에이전트(Claude Code, Cursor, Copilot 등)를 지원하며 "60–90% 토큰 절감"을 벤치마크로 제시.
- **설치**: `curl -fsSL https://leanctx.com/install.sh | sh` (Homebrew/npm/Cargo도 지원)
- **인용**: "Control what your AI can see." — 리포지토리 설명(GitHub repo description)
- **Jayden 적용**: Claude API 사용량이 커질 때 prompt caching/context 관리 대안으로 검토할 만함. 다만 60–90% 절감 수치는 벤치마크 주장이며 자체 재현 전까지는 참고치로만 취급 권장.
