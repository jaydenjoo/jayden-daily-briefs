### [Category 6 — Context Engineering] `coleam00/context-engineering-intro`
- **URL:** https://github.com/coleam00/context-engineering-intro
- **Stars:** 13,300 | Forks: 2,700
- **언어:** Python/Markdown | **라이선스:** MIT
- **요약:** Cole Medin이 만든 PRP(Product Requirements Prompt) 기반 context engineering 입문 repo. Claude Code 전용 slash command(`/generate-prp`, `/execute-prp`)와 `CLAUDE.md` 템플릿, `.claude/` 커맨드 디렉토리 포함.
- **핵심 구조:**
  ```
  .claude/commands/    # /generate-prp, /execute-prp
  PRPs/               # PRP 템플릿 및 예시
  examples/           # 코드 패턴 데모
  CLAUDE.md           # 프로젝트 컨텍스트
  INITIAL.md          # 초기 요구사항 수집 템플릿
  ```
- **PRP 개념:** 단순 프롬프트가 아닌 "무엇을, 어떻게, 어떤 검증으로" 세 축으로 구성된 실행 계획서
- **Jayden 적용:** Next.js 컴포넌트 신규 개발 전 `/generate-prp` 실행 → Supabase 스키마 포함 실행 계획 자동 생성 → `/execute-prp` 로 구현. 비개발자가 "요구사항 정의 → 구현"을 코드 없이 진행하는 최적 패턴.
- **검증:** ✅ 활성도(25 commits, 20 open issues), ✅ Stars 13.3k, ✅ 문서화 충분, ✅ 클론 가능, ✅ 신규

### [Category 1 — Claude Code 아키텍처 분석] `VILA-Lab/Dive-into-Claude-Code`
- **URL:** https://github.com/VILA-Lab/Dive-into-Claude-Code
- **Stars:** 1,100 | Forks: 175
- **요약:** Claude Code v2.1.88 소스코드(~512K lines, 1,884 TypeScript 파일) 체계적 역분석 리포트. 설계 원칙을 소스 레벨까지 추적한 학술적 접근.
- **주요 발견:**
  - Claude Code 코드베이스의 **98.4%는 deterministic 인프라**, AI 의사결정 로직은 1.6%뿐
  - **5단계 compaction** 파이프라인: Budget Reduction → Snip → Microcompact → Context Collapse → Auto-Compact
  - **7개 독립 safety layer** 존재하나, 50개 이상 subcommand가 동시 실행되면 event-loop 과부하 방지를 위해 보안 검사 우회 (공개된 CVE 4개)
  - Hook 아키텍처: ReAct 패턴 while-loop + 도구 라우팅
- **Jayden 적용:** Claude Code hooks 설계 시 "어느 레이어에 무엇을 걸어야 하는가" 판단 근거로 활용. 보안 관련 자동화 도구 사용 시 참고 (PayLoom/PG-System 제외 영역 판단).
- **검증:** ✅ 활성도(커밋 날짜 미확인, 2025-2026 active 커뮤니티 활동), ✅ Stars 1.1k, ✅ 상세 분석 문서, ✅ 클론 가능, ✅ 신규
