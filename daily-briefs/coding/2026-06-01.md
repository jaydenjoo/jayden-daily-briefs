### 1. `Chachamaru127/claude-code-harness`

**카테고리:** Harness 기법
**URL:** https://github.com/Chachamaru127/claude-code-harness
**Stats:** ⭐ 2.4k · 🍴 237 · 최신 릴리스: v4.13.2 (2026-05-30) · 커밋 1,318개

**한 줄 요약:** Claude Code 에이전트 작업을 "Plan → Work → Review → Release" 단일 경로로 구조화하는 harness.

**핵심 내용:**
Claude Code는 강력하지만 에이전트 작업은 쉽게 표류한다 — 플랜은 채팅에 남고, 테스트는 선택이 되며, 리뷰는 뒤늦게 온다. 이 harness는 그 경로를 단일 반복 가능한 루프로 고정한다.

**명령어 세트:**

| 명령어 | 역할 |
|---|---|
| `/harness-plan` | `spec.md` + `Plans.md` 생성 (범위·인수 기준·중단 조건) |
| `/harness-work` | TDD 기반 실행, 계획 범위 내 유지 |
| `/harness-review` | 구현과 독립된 평가, major 발견은 blocker 처리 |
| `/harness-release` | 검증 증거 패키징 |

README 인용: "Your job is not to hand-write the plan. It is to approve or correct the generated contract before execution continues."

**Jayden 스택 적용성:**
Next.js + Supabase 기능 개발 시 `/harness-plan`으로 spec을 사전 계약화하면, 비개발자가 "승인 또는 수정"만 하고 Claude가 계약 내에서 실행. n8n 자동화 트리거와 함께 야간 비지도 실행에도 활용 가능.

**검증 체크리스트:**
- [x] 활성도: v4.13.2 릴리스 = 2026-05-30 (2일 전)
- [x] 신뢰도: ⭐ 2.4k
- [x] 문서화: 명령어별 "First 15 Minutes" 가이드 포함
- [x] 재현성: npm 설치 후 슬래시 명령 즉시 실행 가능
- [x] 신규성: 인덱스 미보고
