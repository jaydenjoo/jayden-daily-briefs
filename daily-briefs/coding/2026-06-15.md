## 🔔 오늘의 핵심 업데이트

**Claude Code v2.1.172 (2026-06-10): 재귀 Subagent 5레벨 허용** — 4개월간 유지되던 "subagent는 다른 subagent를 생성할 수 없다" 제한이 철폐됐다. 계층형 태스크 분해가 코드 단에서 가능해졌으며, 각 레벨마다 별도 system prompt와 모델 지정이 가능하다. 단, 기본 모델을 전 레벨에 Opus로 설정하면 토큰 비용이 7~12배 급증할 수 있어 **모델 티어링 전략**(루트: Opus → 중간: Sonnet → 리프: Haiku)이 필수다.

## 🔌 MCP 사양 업데이트

**MCP Release Candidate 예고 (최종 사양: 2026-07-28)**  
출처: [MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)

핵심 변경 사항:
- **Stateless Core**: sticky session · shared session store 없이 일반 HTTP 인프라에서 운용 가능. 라운드로빈 로드밸런서 뒤에서 동작, `Mcp-Method` 헤더로 라우팅
- **Extensions**: `MCP Apps`(서버-렌더링 UI) · `Tasks`(장기 실행 작업) 확장 추가
- **Authorization 강화**: OAuth·OpenID Connect 정렬
- **Breaking change 포함** → SDK 유지관리자·클라이언트 구현자 대상 10주 검증 기간

**Jayden 적용 포인트:** Supabase + n8n 연동 MCP 서버를 자체 운영 중이라면, stateless 전환 후 인프라 비용이 줄어들 수 있음. 7월 28일 최종 사양 전 Breaking change 목록 확인 필수.
