### 참고 · 공식 Anthropic 블로그

**"Lessons from building Claude Code: Prompt caching is everything"**
저자: Thariq Shihipar (Claude Code 팀 MTS) | 발행: 2026-04-30
[원문 링크](https://claude.com/blog/lessons-from-building-claude-code-prompt-caching-is-everything)

- 핵심 기법 5가지 (1차 출처 직접 확인):
  1. **프롬프트 레이어링**: 정적 시스템 프롬프트 먼저 → 동적 콘텐츠 마지막. 캐시 적중 최대화.
  2. **tool set·모델 고정**: 대화 중 교체 금지 → 캐시 prefix 유지.
  3. **지연 로딩 stub**: `defer_loading: true`로 도구 동적 발견 시 캐시 안정 유지.
  4. **Plan Mode 구현법**: 프롬프트 교체 대신 `EnterPlanMode`/`ExitPlanMode` tool call 사용.
  5. **시스템 업데이트**: 프롬프트 수정 대신 `<system-reminder>` 태그를 user 메시지로 삽입.
- Jayden 적용: Claude API 직접 활용 시 캐시 절감 구현의 공식 가이드. n8n + Claude API 연동 워크플로우에서 시스템 프롬프트 구조화 기준으로 활용.
