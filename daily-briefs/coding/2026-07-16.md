### 1-1. n8n-io/skills — n8n 공식 Claude Code Skills
- **카테고리:** Skills / marketplace
- **출처:** [GitHub repo](https://github.com/n8n-io/skills)
- **검증:** WebFetch로 직접 재확인 — n8n-io 조직 소유, 333 stars, 최근 merge PR #33("rename/skills-official-suffix") 확인. 5개 기준 모두 통과.
- **내용 요약 (의역):** n8n이 자사 인스턴스 레벨 MCP 서버와 짝을 이루는 공식(커뮤니티 아님) skill 팩을 공개. 워크플로우 빌드, 표현식(expressions), 에러 핸들링, 서브워크플로우 재사용, credentials, Data Tables 등을 다루는 13개 capability skill과 50개 이상의 레퍼런스 문서로 구성. `/plugin marketplace add n8n-io/skills` 또는 `npx skills add n8n-io/skills`로 설치, n8n 인스턴스에서 MCP 활성화가 전제조건.
- **기존 보고 항목과의 구분:** 이전에 보고된 `czlonkowski/n8n-mcp`, `czlonkowski/n8n-skills`(둘 다 커뮤니티 제작)와는 별개로, n8n 팀이 직접 만든 공식 skill 저장소라 신규 보고.
- **Jayden 적용 가능성:** Claude Code + n8n 조합을 그대로 쓰는 Jayden 스택에 가장 직접적으로 맞는 항목. 기존 커뮤니티 MCP/skill과 병행 사용 가능한지, 공식 쪽이 유지보수 신뢰도가 더 높은지 비교 검토 권장.

### 1-4. Dicklesworthstone/destructive_command_guard — 파괴적 명령 차단 hook
- **카테고리:** Harness 기법
- **출처:** [GitHub repo](https://github.com/Dicklesworthstone/destructive_command_guard)
- **검증(서브에이전트 수행):** 4,755 stars, 최근 커밋 2026-07-15.
- **내용 요약 (의역):** Claude Code·Codex CLI·Gemini CLI 등에 pre-tool-use hook으로 설치되는 Rust CLI(`dcg`). 셸/git 명령을 실행 전에 가로채 `rm -rf`, `git reset --hard`, `DROP TABLE` 같은 파괴적 명령을 차단. curl 원라이너로 설치, `dcg test`/`dcg explain`, allowlist 설정, 긴급 우회용 env var 지원.
- **Jayden 적용 가능성:** 자율 Claude Code 세션이 실수로 운영 Supabase DB에 파괴적 SQL을 날리는 실질적 리스크에 대한 직접적인 방어선. 다만 PayLoom·PG-System처럼 자동화 도구 사용 금지 영역에는 이 hook 설치 여부와 무관하게 애초에 자동화 자체를 적용하지 않는다는 원칙이 우선.
