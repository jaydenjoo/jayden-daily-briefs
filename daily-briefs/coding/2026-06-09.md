**요약**
Claude Code v2.1.88의 TypeScript 소스 ~1,900개 파일(약 512K 라인)을 정밀 분석한 arXiv 논문 [2604.14228](https://arxiv.org/abs/2604.14228) + 커뮤니티 분석 모음. README에서 핵심 발견:

> "Only 1.6% of Claude Code's codebase is AI decision logic. The other 98.4% is deterministic infrastructure."

분석 항목:
- **Agent loop:** ReAct 패턴 while-loop + streaming event yield 구조
- **Permission system:** deny-first 원칙의 7개 독립 안전 레이어
- **Context 관리:** 5단계 압축 전략 (Budget Reduction → Snip → Microcompact → Context Collapse → Auto-Compact)
- **확장 메커니즘 4단계:** hooks → skills → plugins → MCP servers (순서대로 권한/복잡도 상승)
- **Subagent delegation:** 격리된 context + sidechain transcript 요약

**Jayden 적용 가능성**
CLAUDE.md 작성 시 "어디까지가 advisory(~70% 이행)이고 어디부터 hook(100% 강제)인지"를 결정하는 공식 근거로 활용 가능. 확장 메커니즘 4단계 이해는 n8n ↔ Claude Code 연동 설계에 직접 참조값.

### [카테고리 6 — Context Engineering]

#### `mksglu/context-mode`
- **URL:** https://github.com/mksglu/context-mode
- **Stars:** ~16K | **최근 커밋:** 2026-06-08 | HN Show HN 게시 후 주목
- **검증 통과:** 활성도 ✅ 신뢰도 ✅ 문서화 ✅ 재현성 ✅ 신규성 ✅

**요약**
AI coding agent의 context window 최적화 MCP 서버. 도구 출력을 샌드박스에서 처리해 **315 KB → 5.4 KB(98% 감소)**, 세션 지속 시간 30분 → 3시간으로 연장 보고. SQLite FTS5 + BM25 ranking + Porter stemming 사용 (LLM 호출 없음).

핵심 작동 방식:
1. 파일 작업·git commit → 직접 실행 (컨텍스트 진입)
2. 나머지 도구 출력 → 샌드박스 subprocess 처리 → 요약만 컨텍스트 진입
3. 전체 데이터는 로컬 SQLite에 세션 범위로 유지, 종료 시 삭제

Claude Code 설치:
```
/plugin marketplace add mksglu/context-mode
/plugin install context-mode@context-mode
```

지원 플랫폼: Claude Code, Gemini CLI, Cursor, VS Code Copilot, OpenCode 등 15개+.

**Jayden 적용 가능성**
Claude Code 세션 비용·토큰 소모 절감에 직접 기여. 특히 Agent SDK metered 과금 전환 이후 중요도 상승. n8n 자동화로 대용량 데이터 처리 시 context 폭발 방지에 활용 가능.
