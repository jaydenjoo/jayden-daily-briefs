**카테고리**: Harness 기법  
**현황**: ⭐4.5k · 최신 릴리즈 v0.0.56 (2026-06-18) · Beta Research Preview  
**링크**: https://github.com/anthropic-experimental/sandbox-runtime

Claude Code를 위해 Anthropic이 직접 만든 OS 수준 샌드박스 툴. 컨테이너 없이 파일시스템·네트워크 제한을 arbitrary 프로세스에 적용한다. macOS는 `sandbox-exec`, Linux는 `bubblewrap` 활용.

- MCP 서버 sandboxing 지원 (`.mcp.json` 연동)
- Unix socket controls + Linux seccomp 필터링

### 2. `rohitg00/agentmemory`
**카테고리**: MCP Servers + Context Engineering  
**현황**: ⭐23.7k · v0.9.27 (2026-06-07) · Apache-2.0  
**링크**: https://github.com/rohitg00/agentmemory

AI 코딩 에이전트의 세션 간 메모리 단절 문제를 해결. 자동으로 에이전트 행동을 캡처·압축·저장하여 다음 세션 시작 시 관련 컨텍스트를 주입한다.

**4계층 메모리 파이프라인**:
1. Working memory (원시 관찰)
2. Episodic memory (세션 요약)
3. Semantic memory (추출된 사실·패턴)
4. Procedural memory (워크플로우·결정)

**검색 방식**: BM25 키워드 + 벡터 임베딩 + 지식 그래프 3중 hybrid retrieval (Reciprocal Rank Fusion)

**Claude Code 설치**:
```
/plugin marketplace add rohitg00/agentmemory
/plugin install agentmemory
```
→ 12개 hook, 15개 skill, **53개 MCP tool** 자동 등록

**Jayden 적용 포인트**: Claude Code 세션이 끊겨도 다음 세션에서 이전 Supabase 스키마 결정, n8n 워크플로우 패턴, Next.js 아키텍처 맥락을 자동 recall. 반복 설명 제거로 토큰 절약.
