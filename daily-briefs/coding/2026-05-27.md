### [Cat. 1] Claude Code v2.1.147-149 (2026-05-22~23)
출처: https://releasebot.io/updates/anthropic/claude-code

**핵심 변경 3가지:**

1. **`/simplify` → `/code-review` 리네임 (v2.1.147)**  
   effort level 지정 가능 (`/code-review high`), `--comment`로 GitHub PR에 inline 코멘트 직접 게시.

2. **`/usage` 카테고리별 상세 내역 (v2.1.149)**  
   limits 사용량을 카테고리별로 breakdown해 표시.

3. **background session 개선 (v2.1.147)**  
   pin된 background session은 idle 상태에서도 유지되며 업데이트 시 재시작.

**Jayden 적용:** `/code-review high --comment`로 PR 리뷰 자동화 연결. n8n에서 GitHub PR event → Claude Code `/code-review` 트리거 패턴 설계 가능.

### [Cat. 1] Claude Code Week 19 — sub-agent cache 비용 3× 절감
출처: https://code.claude.com/docs/en/whats-new/2026-w19 (v2.1.128, 2026-05-04)

**핵심 변경 (Jayden 관련 우선순위 순):**

| 변경 | 내용 | 중요도 |
|------|------|--------|
| **Sub-agent 캐시 최적화** | progress summary가 prompt cache hit → `cache_creation` 토큰 약 3× 감소 | 🔴 높음 (비용 직결) |
| **Hooks에 effort level 전달** | `effort.level` JSON 필드 + `$CLAUDE_EFFORT` env var로 hooks에서 effort 수신 가능 | 🟠 중간 |
| **`autoMode.hard_deny`** | auto mode에서 특정 액션을 조건 없이 차단하는 deny rule 추가 | 🟠 중간 (보안) |
| **`worktree.baseRef`** | worktree 분기점 설정 (`fresh` = remote default, `head` = local HEAD) | 🟡 낮음 |
| **Plugin from URL** | `--plugin-url`로 URL에서 plugin 직접 로드 | 🟡 낮음 |

**Jayden 적용:** sub-agent를 다수 사용하는 멀티-agent 워크플로우에서 비용이 자동으로 줄어듦. `hard_deny` rule로 PayLoom·PG-System 관련 경로는 auto mode에서 완전 차단 설정 권장.

### [Cat. 4] MCP Tunnels (Research Preview, 2026-05-19)
출처: https://www.infoq.com/news/2026/05/claude-mcp-tunnels/

**핵심:** Managed Agents + Messages API에서 private MCP 서버를 공인 IP 노출 없이 연결 가능.

**동작 방식:** 방화벽 inbound 규칙 오픈 대신, 경량 gateway를 내부에 배포 → Anthropic 인프라로 outbound 암호화 연결 수립.

**현재 상태:** Research Preview (Claude Console 조직 설정에서 관리).

**같이 공개된 것:** Self-hosted sandboxes (Public Beta) — Cloudflare, Daytona, Modal, Vercel에서 tool execution 실행 가능.

**Jayden 적용:** 현재는 research preview라 프로덕션 적용 이름. 단, Supabase DB나 내부 n8n 서버를 Claude agent에 안전하게 연결하는 아키텍처가 가능해지는 방향. 주시 필요.
