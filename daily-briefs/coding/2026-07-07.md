## 4. Harness 기법

### Anthropic 공식 — Dynamic Workflows in Claude Code

- **인용**: "Claude can now write its own harness on the fly, custom-built for the task at hand." / "Because static workflows need to work for all edge cases, they are usually more generic. With Claude Opus 4.8 and dynamic workflows, Claude is now intelligent enough to write a custom harness tailor-made for your use case." (Anthropic 공식 블로그, 2026-06-02)
- **검증**: 1차 출처(Anthropic 공식) / 90일 이내(35일 전) / Hacker News 토론 존재로 커뮤니티 검증 확인(news.ycombinator.com/item?id=48311705, 2026-06-03) — 신뢰도 통과.
- **Jayden 적용**: Cowork/Routines에서 반복적인 대규모 조사·마이그레이션 작업이 필요할 때 "정적 워크플로우 vs 동적 워크플로우" 구분을 이해하는 것이 핵심. 다만 Jayden은 비개발자 포지션이므로 직접 스크립트 작성보다 "언제 이 기능을 요청하면 좋은가"의 판단 기준으로 활용.

## 5. Context Engineering

### volcengine/OpenViking
- **무엇**: Agent 메모리·지식 RAG·Skills를 하나로 통합하는 오픈소스 "Context Database". 벡터 저장소 분산 모델 대신 파일시스템 패러다임으로 컨텍스트를 통합 관리.
- **인용**: "OpenViking is an open-source Context Database designed specifically for AI Agents. We aim to define a minimalist context interaction paradigm for Agents, allowing developers to completely say goodbye to the hassle of context management." (README)
- **검증**: Star 26.4k(통과) / 최근 커밋 2026-07-02(v0.4.7, 5일 전, 통과) / 문서화(통과, `ov add-resource`/`ov find`/`ov grep`/`ov tree` 등 CLI 예시 + LoCoMo/tau2-bench/HotpotQA 벤치마크 결과 공개) / 재현 가능(`pip install openviking`, `npm i -g @openviking/cli`) / 신규(통과) — **5/5 통과**
- **Jayden 적용**: Supabase 기반 메모리·RAG 구조를 설계할 때 참고할 "컨텍스트 DB" 아키텍처 사례. 다만 프로덕션 도입 전 벤치마크 재현은 별도 검증 필요.
