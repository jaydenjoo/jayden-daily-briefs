### Ecosystem 업데이트: Claude Code v2.1.172 → v2.1.181 (June 10–18, 2026)

소스: [releasebot.io/updates/anthropic/claude-code](https://releasebot.io/updates/anthropic/claude-code)

이번 주 가장 중요한 변경사항 요약:

**v2.1.172 (June 10) — 중첩 subagent 해제**
- Sub-agent가 자신의 sub-agent를 spawn 가능 → 최대 **5단계 깊이**
  - 서버사이드 강제 제한 (설정 변경 불가)
  - 기존 공식 문서에서 명시적으로 불가능이라고 했던 기능을 해제
- `/cd` 명령: 세션 이동 시 prompt cache 유지
- `--safe-mode`: MCP 없이 트러블슈팅
- Searchable plugin marketplace 도입
- PostSessionEnd lifecycle hook 추가

**v2.1.178 (June 16) — 정밀 permission 문법**
- `Tool(param:value)` 문법으로 특정 파라미터까지 지정한 세밀한 허용/차단 규칙 작성 가능
- 중첩 `.claude` 디렉토리 지원

**v2.1.181 (June 18) — 설정 UX 개선**
- 프롬프트 기반 config 명령 (자연어로 설정 변경)
- macOS sandbox 옵션 신규 추가
- Bun 런타임 1.4 업그레이드
- 긴 단락을 첫 줄 기다리지 않고 line-by-line 출력

**Jayden 적용 포인트:**  
orchestrator(상위) → researcher(하위) → coder(최하위) 3단계 계층 구조가 공식 지원됨. n8n에서 트리거 → Claude Code 최상위 에이전트 → 병렬 서브에이전트 패턴 설계 가능.

## 5. Harness 기법

### [omnigent-ai/omnigent](https://github.com/omnigent-ai/omnigent)

**검증 체크:**
- [x] 30일 내 커밋: 2026-06-13 오픈소스 출시
- [x] Star 50+: 3,800
- [x] README + 설치법: ✓
- [x] 재현성: curl 설치 스크립트 + YAML 에이전트 정의
- [x] 신규성: ✓ (인덱스 미보고)

**핵심:**  
Databricks가 오픈소스로 공개한 AI agent meta-harness. Claude Code, Codex, Cursor, Pi, 커스텀 에이전트를 **단일 orchestration 레이어**에서 관리.

**핵심 차별점:**
- 에이전트를 YAML로 선언적 정의 → 하네스/모델 전환은 파일 한 줄 수정
- 정책(shell 접근, 지출 한도, tool 사용)을 meta-level에서 **모든 하네스에 일괄 적용**
- Cloud sandbox: Modal, Daytona, Islo에서 disposable 환경 실행
- 팀 협업: 세션 공유, 공동 제어(co-drive), 포크, 초대

**아키텍처 비교:**
| 구분 | 기존 harness (ECC 등) | Omnigent (meta-harness) |
|---|---|---|
| 대상 | 단일 harness 최적화 | 여러 harness 간 orchestration |
| 정책 적용 | harness별 각각 설정 | meta-level 일괄 적용 |
| 에이전트 정의 | `.md` 파일 | YAML 선언적 정의 |
| 팀 협업 | 제한적 | 네이티브 지원 |

**설치:**
```bash
curl -fsSL https://raw.githubusercontent.com/omnigent-ai/omnigent/main/scripts/install_oss.sh | sh

omnigent                          # 대화형 설정
omnigent run examples/polly/      # 다중 에이전트 예시
omnigent run examples/debby/      # 2-에이전트 브레인스토밍
```

**Jayden 적용 가능성:**  
현재 1인 워크플로우에서는 오버엔지니어링일 수 있음. 단, 클라이언트 프로젝트에서 Claude Code + Codex를 함께 쓰거나, 여러 에이전트에 일관된 지출 한도를 적용할 때 유용. Alpha 상태이므로 프로덕션 전에 샌드박스 테스트 필수.
