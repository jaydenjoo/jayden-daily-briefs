**한 줄 요약:** Claude Code를 Python으로 직접 제어하는 공식 SDK — in-process MCP tool, 세밀한 권한 제어, PreToolUse hook 지원.

**재사용 패턴:**
```python
# 결제 관련 Bash 명령을 hook으로 차단하는 예시
from claude_agent_sdk import HookMatcher, ClaudeAgentOptions

async def block_payment_commands(input_data, tool_use_id, context):
    command = input_data.get("tool_input", {}).get("command", "")
    if any(kw in command for kw in ["payment", "billing", "payloom"]):
        return {
            "hookSpecificOutput": {
                "hookEventName": "PreToolUse",
                "permissionDecision": "deny",
                "permissionDecisionReason": "결제 영역 자동화 차단"
            }
        }
    return {}

options = ClaudeAgentOptions(
    allowed_tools=["Bash", "Read", "Write"],
    hooks={"PreToolUse": [HookMatcher(matcher="Bash", hooks=[block_payment_commands])]}
)
```

**Jayden 적용:** n8n 워크플로우에서 Claude를 서브에이전트로 호출할 때 Python SDK 레이어를 두면, PayLoom·PG-System 관련 Bash 명령을 hook으로 자동 차단 가능. `allowed_tools`/`disallowed_tools`로 세밀한 권한 격리.  
**문서:** https://platform.claude.com/docs/en/agent-sdk/python
