### [카테고리 6 · Context Engineering] mksglu/context-mode

**링크:** <https://github.com/mksglu/context-mode>  
**Stars:** 16k | **최근 커밋:** 2026-05-29 | **라이선스:** ELv2

**요약:** tool 출력을 sandbox에 격리해 raw data가 context window에 유입되지 않도록 막는 MCP 레이어. 315KB → 5.4KB (98% 절감) 달성. Claude Code hooks(PreToolUse, PostToolUse, SessionStart, PreCompact)로 hook-capable 플랫폼에서 ~98% 준수율 확보.

**검증 체크리스트:**
- [x] 활성도: 2026-05-29 커밋
- [x] 신뢰도: 16k Stars, Microsoft/Google/Meta/Supabase 등 도입 사례 명시
- [x] 문서화: 11개 tool 상세 + 실측 수치 표
- [x] 재현성: `npm install -g context-mode` 또는 Claude Code 마켓플레이스 원클릭
- [x] 신규성: 첫 보고

**핵심 tool (실측 절감률):**

| Tool | 역할 | 절감 |
|------|------|------|
| `ctx_execute` | 12개 언어 실행, stdout만 반환 | 56KB → 299B |
| `ctx_batch_execute` | 다중 명령어 일괄 처리 | 986KB → 62KB |
| `ctx_search` | BM25로 indexed content 조회 | on-demand |
| `ctx_fetch_and_index` | URL fetch + 24h TTL 캐시 | 60KB → 40B |

**세션 효과:** 컨텍스트 소진까지 ~30분 → ~3시간

**설치:**
```bash
# Claude Code (한 줄)
/plugin marketplace add mksglu/context-mode

# 다른 플랫폼
npm install -g context-mode
```

**Jayden 적용:** Next.js 프로젝트에서 대용량 Supabase 쿼리 결과나 n8n 실행 로그가 context를 빠르게 채우는 문제를 이 레이어로 해결 가능. Supabase 연동 시 DB 조회 결과를 `ctx_execute`로 격리하면 context 수명이 6배 연장됨.
