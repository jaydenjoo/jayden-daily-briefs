- **출처**: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
- **성격**: 사양 변경 공지 (repo가 아닌 spec 업데이트)

**RC의 핵심 변경사항 (사양 문서 기반 요약):**

| 변경 | 현재 | RC 이후 |
|------|------|---------|
| 세션 관리 | sticky session 필요 | 완전 stateless, 라운드로빈 LB 가능 |
| 툴 로딩 | 세션 시작 시 전체 로드 | `ttlMs` 캐싱, 클라이언트 측 tools/list 캐시 |
| Gateway | deep packet inspection 필요 | `Mcp-Method` 헤더로 라우팅 |

**추가 도입 예정**: Extensions framework, Tasks, MCP Apps, Authorization 강화, 공식 deprecation 정책

**공식 SDK 현황**: TypeScript, Python, C#, Java, Swift (Tier 1 SDK는 10주 내 지원 예정)
**커뮤니티 서버**: 공개 서버 500개+ 달성

**Jayden 적용성**: 현재 MCP 서버 운영 방식(sticky session)에서 벗어날 수 있음. Supabase·n8n 연동 MCP 서버를 단순 HTTP 서버로 배포 가능해짐. Tool Search가 이미 기본 활성화돼 컨텍스트 오염 없이 더 많은 서버 등록 가능.

**주의**: 이 RC는 2026-07-28 확정 예정. 현재(6월)는 10주 검증 기간 시작 시점. 프로덕션 적용은 8월 이후 권장.

**핵심 발견 — "98/2 원칙":**
전체 코드베이스 중 AI 결정 로직은 1.6%뿐. 나머지 98.4%는 결정론적 인프라(권한 게이트, 컨텍스트 관리, 툴 라우팅, 복구 로직).

→ 에이전트 능력은 모델이 아닌 harness에서 나온다.

**7계층 안전 설계 (deny-first):**
모든 툴 파이프라인에 독립적 보호 경계 존재. Permission 모드 스펙트럼:
`plan → default → acceptEdits → auto → dontAsk → bypassPermissions`

**5단계 컨텍스트 압축:**
`Budget Reduction → Snip → Microcompact → Context Collapse → Auto-Compact`

**서브에이전트 설계 원칙**: 격리된 컨텍스트, 요약만 부모에게 반환 → 컨텍스트 폭발 방지

**Jayden 적용성**: Claude Code의 동작 원리를 설계 수준에서 이해하면 CLAUDE.md·hooks 설계가 달라짐. 비개발자가 "왜 이렇게 쓰는가"를 납득하는 데 최적.

## [CAT 6] Context Engineering

### rohitg00/agentmemory
- **URL**: https://github.com/rohitg00/agentmemory
- **Star**: ⭐ 22.3k | 최신: v0.9.27 (2026-06-07) ✅ | 라이선스: Apache-2.0
- **설명**: 코딩 에이전트용 영구 메모리 시스템. 에이전트가 세션 사이에 컨텍스트를 기억해 매번 재설명하는 비용 제거.

**4단계 파이프라인:**
1. **Capture**: hook으로 도구 사용 인터셉트 (SHA-256 중복 제거, 시크릿 필터링)
2. **Compress**: LLM이 관측값을 구조화된 사실·개념으로 압축
3. **Index**: BM25 + 벡터 임베딩 + 지식 그래프 저장
4. **Inject**: SessionStart 시 하이브리드 검색으로 상위 K 메모리 주입

**메모리 4계층**: working → episodic → semantic → procedural (decay + 자동 망각)

**기술 스택**: TypeScript 83%, SQLite, BM25+임베딩+RRF fusion, 로컬 임베딩(`all-MiniLM-L6-v2`) 또는 클라우드
**지원 에이전트**: 30개+ (Claude Code, Cursor, GitHub Copilot CLI, Cline, Windsurf 등)

**Jayden 적용성**: 세션마다 Next.js·Supabase 아키텍처를 재설명하는 번거로움 제거. Claude Code와 hook 연동으로 자동 작동. Apache-2.0으로 수정·배포 자유.

**검증 체크리스트**: 5/5 ✅
