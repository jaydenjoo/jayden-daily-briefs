### "Harness design for long-running application development"
**URL:** https://www.anthropic.com/engineering/harness-design-long-running-apps
**발행일:** 2026-03-24

GAN 구조에서 영감받은 3종 multi-agent harness 아키텍처 소개.

**3가지 하네스 변형:**

| 변형 | 에이전트 구성 | 핵심 특징 |
|---|---|---|
| Frontend Harness | Generator + Evaluator | Playwright로 라이브 페이지 테스트, 5-15회 반복 |
| Full-Stack v1 | Planner + Generator + Evaluator | 스프린트 계약 기반 단계별 검증 |
| Simplified v2 | Planner + Generator (선택적 Evaluator) | 개선 모델 대상, 스프린트 분해 제거 |

**핵심 권고:**
- "context anxiety"가 있는 모델은 compaction 대신 context reset 사용
- 생성(Generation)과 평가(Evaluation)는 항상 분리 — 자기 평가 편향 제거
- 모델 업그레이드 시 scaffolding 제거 후 가정 재검증
