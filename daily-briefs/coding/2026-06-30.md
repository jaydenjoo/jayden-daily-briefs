### [2] "Advanced Claude Code Techniques: Agentic Engineering With Context Driven Development"

**채널:** Cole Medin — 사전 승인 신뢰 채널  
**행사:** JSNation US 2025 (컨퍼런스 발표)  
**발표일:** 2025-11-17 *(225일 경과 — 신선도 기준 미달. 단, GitNation 공식 전사본 확보 + 연관 GitHub repo 현재 ★13.5K 활성으로 예외 포함)*  
**길이:** 29분  
**전사본 출처:** https://gitnation.com/contents/advanced-claude-code-techniques-agentic-engineering-with-context-driven-development-3256

**핵심 주장:** "Vibe coding"을 넘어서려면 CLAUDE.md·on-demand context·commands·validation의 4가지 시스템 컴포넌트와 PIV 루프(Plan-Implement-Validate)를 구조화해야 한다. 오류는 버그가 아니라 시스템 gap의 신호다.

**워크플로우 (GitNation 전사본 기반):**
1. CLAUDE.md에 간결한 global rules 정의 (길면 context rot 발생)
2. 기능 요청을 `INITIAL.md` 템플릿에 작성
3. `/generate-prp` 명령으로 구현 청사진(PRP: Product Requirements Prompt) 자동 생성
4. `/execute-prp` 명령으로 PRP 기반 구현 실행
5. E2E 테스트로 검증 (unit test만으로는 통합 실패 미감지)
6. 오류 발생 시 원인 분석 → rules/context 업데이트 (시스템 개선 루프)

**사용 도구/repo:** `coleam00/context-engineering-intro` (★13.5K) — `.claude/`, `PRPs/`, `examples/`, `CLAUDE.md`, `INITIAL.md` 포함

**Jayden 적용 가능성:**
- `/generate-prp` → `/execute-prp` 패턴은 n8n 워크플로우 자동화와 유사한 구조적 접근
- Next.js 프로젝트에서 CLAUDE.md + PRP로 반복 패턴 기록 → 다음 세션에서 재사용
- 비개발자 관점: "오류 = 시스템 개선 신호"라는 사고방식 전환이 핵심

**시청 권장도:** 🟢 핵심만 (GitNation 전사본 + GitHub repo로 내용 소화 가능 — 영상 시청보다 전사본 읽기 권장)
