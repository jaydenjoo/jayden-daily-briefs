### [카테고리: Multi-agent / Claude Managed Agents]
**Code with Claude 2026: Opening Keynote (San Francisco)**

**링크:** https://www.youtube.com/watch?v=GMIWm5y90xA  
**채널:** Anthropic / Claude 공식  
**업로드:** 2026-05-06  
**길이:** 미확인  
**자막 확보:** ❌ (자막 미추출 — 외부 1차 리포팅 기반: simonwillison.net, InfoQ, MindStudio)

**핵심 주장:** Anthropic이 Claude Managed Agents에 Multiagent Orchestration·Outcomes·Dreaming 세 기능을 추가. "The default isn't 'I'm going to prompt Claude' — the default is now 'I'm going to have Claude prompt itself'" (Boris Cherny, Head of Claude Code).

**시연 워크플로우:** *(자막 미확인 — 기재 생략)*

**사용 도구:** 확인 불가 (자막 미확인)

**외부 리포팅 기반 내용 요약:**

1. **Multiagent Orchestration** (공개 베타): 코디네이터 에이전트가 복잡한 task를 서브에이전트에 병렬 분배. 분해(decomposition)·컨텍스트 배포·결과 집계·충돌 해소 자동 처리.
2. **Outcomes** (공개 베타): 루브릭 기반 자기 평가 루프. 평가 에이전트가 루브릭에 따라 출력을 채점하고 수정 지시. 자동 품질 검증 워크플로우 구현 가능.
3. **Dreaming** (리서치 프리뷰, 접근 신청 필요): 세션 사이에 에이전트가 이전 세션 패턴을 추출해 다음 세션 메모리에 기록. Harvey 법률 AI 파일럿에서 task 완료율 약 6배 향상 보고.
4. **Routines**: 비동기 자동화 활성화로 개발자가 merge-ready PR을 받는 형태의 워크플로우.
5. **CI Auto-fix**: PR에 자동 수정 적용.

**Jayden 스택 적용 가능성:**  
n8n 자동화 → Claude Managed Agents 전환 검토 시 Multiagent Orchestration이 직접 참고 대상. Outcomes는 Claude Code가 생성한 Next.js 코드 품질을 자동 루프로 검증하는 패턴에 적용 가능. Dreaming은 접근 신청 후 장기 프로젝트 메모리 패턴으로 활용 가능.

**시청 권장도:** 🟡 — 외부 요약으로 핵심 파악 가능. Routines 및 자동화 기능에 관심 있으면 본인 시청 권장.
