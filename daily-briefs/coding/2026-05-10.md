### 6. Context Engineering

- **활성도:** 83 커밋, 3주 전 업데이트 확인 ✅
- **검증:** Star 3.1k ✅ · MIT ✅ · 문서화 ✅ · 신규 ✅
- **내용:** 프롬프트 엔지니어링에서 프로덕션 AI 시스템까지 아우르는 context engineering 종합 서베이.

  **핵심 카테고리:** Context Scaling / Memory Systems (MemGPT, Mem0) / RAG (GraphRAG 포함) / Agent Communication (MCP, A2A, AG-UI) / Tool Use / Evaluation & Observability

- **핵심 인사이트:** **"Context failures are the new bottleneck"** — 2026년 agentic 시스템에서 모델 추론 능력보다 context 품질이 산출물 품질을 결정하는 핵심 변수가 됨.
- **실용 포인트:**
  - Claude API prompt caching → 반복 context 패턴 비용 75~90% 절감
  - 조건부 규칙 로딩 (path/task 기반, 전역 주입 지양)
  - CLAUDE.md 계층 구조 최적화 (세션 시작 시 전체 로드 → 필요 시점 로드로 전환)
- **Jayden 적용:** Next.js + Supabase + Claude API 스택의 API 비용 절감과 응답 품질 향상 동시 달성 가능한 방법론.
