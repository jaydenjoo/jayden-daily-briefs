- **요약:** Claude Code 13가지 hook lifecycle 이벤트 전체를 UV 단일 파일 Python 스크립트로 구현한 학습 repo. `.claude/hooks/`에 인라인 의존성 선언 방식으로 venv 없이 포터블하게 동작.
- **포함 hook 이벤트 (13종):** UserPromptSubmit, PreToolUse, PostToolUse, Notification, Stop, SubagentStart, SubagentStop, PreCompact, SessionStart, SessionEnd, PermissionRequest, PostToolUseFailure, Setup
- **핵심 패턴:**
  - hook 리턴값 `{"decision": "block"}` + exit code 2로 LLM 결정 없이 실행 차단
  - Builder/Validator agent 쌍으로 팀 기반 검증 패턴
  - `.claude/agents/` 아래 YAML frontmatter markdown으로 sub-agent 정의
  - "agent를 만드는 agent(meta-agent)" 패턴으로 specialized sub-agent 자동 생성
- **Jayden 적용:** Next.js 프로젝트에 `PostToolUse` hook → prettier 자동 실행으로 CLAUDE.md "always run prettier" 지시 제거 가능
- **검증:** Star 50+ ✅ | README 사용법 ✅ | UV 스크립트 재현 가능 ✅ | 인덱스 신규 ✅ | 최신 커밋 미확인 ⚠️
