## ⚡ [특보] Claude Code Dynamic Workflows 정식 출시 (2026-06-01)

**카테고리:** AI Agents / Subagents 아키텍처  
**1차 출처:** [code.claude.com/docs/en/workflows](https://code.claude.com/docs/en/workflows) | [claude.com/blog/a-harness-for-every-task](https://claude.com/blog/a-harness-for-every-task-dynamic-workflows-in-claude-code)

### 핵심 주장

공식 문서: "A dynamic workflow is a JavaScript script that orchestrates subagents at scale. Claude writes the script for the task you describe, and a runtime executes it in the background while your session stays responsive."

### 기술적 작동 방식

- Claude가 JavaScript 오케스트레이션 스크립트를 작성하고 런타임이 백그라운드 실행
- 중간 결과가 context window가 아닌 **스크립트 변수에 저장** → context 오염 없음
- 최대 동시 실행: **16 agents** / 런당 최대: **1,000 agents**
- 중단 후 재개 가능 (같은 세션 내), 완료된 agent 결과 캐싱

### Subagent vs Agent Teams vs Workflows 비교

| 항목 | Subagents | Agent Teams | **Workflows** |
|------|-----------|-------------|---------------|
| 계획 주체 | Claude (턴 단위) | Lead agent | 스크립트 |
| 중간 결과 위치 | Context window | 공유 task list | 스크립트 변수 |
| 재현 가능 단위 | Worker 정의 | 팀 정의 | 오케스트레이션 자체 |
| 규모 | 소수 위임 | 소수 장기 | 수십~수백 |
| 중단 처리 | 턴 재시작 | 팀원 유지 | **재개 가능** |

### 6가지 내장 패턴 (공식 문서)

| 패턴 | 용도 |
|------|------|
| classify-and-act | 입력 분류 후 전문 agent 라우팅 |
| fan-out-and-synthesize | 병렬 검색 후 결과 합성 |
| adversarial verification | 독립 agent 간 교차 검증 |
| generate-and-filter | 생성 후 필터링 |
| tournament | 비교 판단 (안 여러 개 → 최적 선택) |
| loop-until-done | 조건 충족까지 반복 |

### 사용법

```bash
# 프롬프트에 ultracode 키워드 포함
ultracode: audit every API endpoint under src/routes/ for missing auth checks

# 또는 내장 workflow 실행
/deep-research What changed in the Node.js permission model between v20 and v22?

# 세션 전체에 자동 workflow 적용
/effort ultracode
```

### 요구사항

- Claude Code **v2.1.154+** 필요 (연구 미리보기 상태)
- 유료 플랜 (Pro, Max, Team, Enterprise)
- Amazon Bedrock / Google Cloud Vertex AI / Microsoft Foundry에서도 사용 가능

### Jayden 스택 적용 가능성

- Next.js + Supabase 코드베이스 전체 보안 감사 자동화 (fan-out-and-synthesize 패턴)
- n8n workflow 설계와 개념 유사 → 빠른 멘탈 모델 적용 가능
- 저장된 workflow는 `.claude/workflows/`에 커맨드로 등록 → 팀 공유 가능
- **⚠️ 비용 주의:** 대규모 task는 토큰 사용량 급증. 소규모 테스트 먼저 권장.
