## 5. Harness 기법

### 🔥 주요 발표 — GitHub Agentic Workflows Public Preview (2026-06-11)

공식 발표: https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview/

GitHub Actions에 AI coding agent(Claude Code, Codex, Copilot CLI 등)를 CI/CD 루프에 내장하는 공식 기능이 Public Preview에 진입했다.

**작동 방식**:
1. 자동화 로직을 자연어 Markdown으로 정의
2. `gh aw` CLI가 이를 표준 GitHub Actions YAML(`.lock.yml`)로 컴파일
3. AI agent가 컨테이너 환경에서 스케줄·수동 실행

**핵심 통제 기능**:
- `max-ai-credits`: 실행당 AI 크레딧 예산 상한 설정
- OpenTelemetry: 토큰·비용 데이터를 OTLP 백엔드로 내보내기
- 프롬프트 인젝션, 권한 탈취, 의도치 않은 액션 방어 아키텍처 내장

**Jayden 적용**: Next.js 프로젝트의 PR 자동 triage, CI 실패 분석, 문서 자동 업데이트를 harness 형태로 구성 가능. 단, **PayLoom·PG-System은 적용 제외** (보안 분류 준수).
