  - [x] 문서화: 3가지 사용 모드 예시 포함 ✅

- **사용법:**
  ```bash
  headroom wrap claude          # Claude Code 자동 래핑
  headroom proxy --port 8787    # 드롭인 프록시
  headroom perf                 # 실제 절감 지표 확인
  ```
- **Jayden 적용:** 대형 코드베이스나 긴 n8n 워크플로우 JSON을 Claude에 붙여넣기 전 headroom이 자동 압축. 컨텍스트 비용 절감에 즉각적 효과. `headroom learn`으로 실패 세션에서 패턴을 학습해 압축 품질 개선 가능.
