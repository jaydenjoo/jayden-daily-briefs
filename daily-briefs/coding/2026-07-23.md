## 2. YouTube — 오늘의 학습

### 🔵 필시청: How to Build Claude Subagents Better Than 99% of People
- **채널**: Nate Herk | AI Automation (구독자 약 866,000)
- **업로드**: 2026-06-09 · **길이**: 26:42 · **링크**: https://www.youtube.com/watch?v=e18sdZLwP7o
- **검증**: 자막(영문, 자동 생성) 직접 추출·전문 확인 완료 / 채널은 영상 내에서 자체 언급된 이전 영상("Claude Code 기능 랭킹", "dynamic workflows", "agent teams")으로 동일 주제 반복 게시 정황 확인 / 30분 이내 / 90일 이내 신선도 충족. **5/5 통과**

**핵심 주장 (한 줄)**: subagent의 본질은 "독립된 fresh 컨텍스트 + 별도 모델 배정"이며, skill과 동일하게 YAML frontmatter + markdown 본문 구조를 쓰지만 실행 방식(메인 세션 내 vs 격리된 세션)이 다르다.

**시연된 워크플로우 단계** (자막 기준):
1. `.claude/agents/*.md` 파일 생성 — YAML frontmatter에 `name`, `description`, `tools`(또는 disallowed tools로 read-only 강제), `model`, `color`, `memory` 지정
2. Claude Code 내 `/agents` 슬래시 커맨드 → "Generate with Claude"로 자연어 설명만 입력해 subagent 자동 생성 (project/personal/global 스코프 선택)
3. `description`을 정밀하게 다듬어 "misfire"(의도한 상황에 발동 안 함/불필요하게 발동함) 방지 — 실사용하며 반복 테스트·수정
4. project-level(`.claude/agents`, repo에 포함되어 팀과 공유) vs global-level(`~/.claude`, 개인 전용) 스코프 구분해 배치
5. 저비용 모델(Haiku)로 리서치·요약형 subagent를 실행하고 메인 세션은 고비용 모델(Opus) 유지해 비용 절감
6. `max_turns` 설정으로 subagent의 루프(무한 리서치·리뷰 반복) 방지
7. Opus 4.8 도입 기능인 "dynamic workflows"(트리거 단어를 `workflow`에서 `ultra code`로 변경)로 다수 subagent(예시 41개, 개인 테스트에서는 210개)를 동시 실행 — 세션 토큰 한도 소모가 크므로 주의

**사용된 도구·repo**: Claude Code(터미널/데스크톱앱/VS Code 확장), `.claude/agents/`·`.claude/skills/` 디렉터리, GitHub 저장소 `VoltAgent/awesome-claude-code-subagents`(영상 내 직접 언급 및 하단 설명란 링크 예고)

**Jayden 스택 적용 가능성**: Claude Code 메인 사용자이므로 오늘 바로 적용 가능. 특히 "read-only tool 제한 + 특정 MCP 서버만 허용" 패턴은 PayLoom·PG-System처럼 자동화 도구 반입이 금지된 영역과, 그 외 일반 영역을 subagent 권한으로 물리적으로 분리하는 데 참고할 수 있음. `max_turns` 설정은 n8n에서 트리거되는 배치성 Claude Code 작업의 폭주 방지에도 이식 가능.
