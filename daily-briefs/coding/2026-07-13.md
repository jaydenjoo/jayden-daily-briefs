### 2. [AI Agents / Subagents 아키텍처] open-multi-agent/open-multi-agent
- **링크**: https://github.com/open-multi-agent/open-multi-agent
- **요약**: TypeScript 기반 멀티에이전트 오케스트레이션 프레임워크. 목표(goal)를 설명하면 coordinator가 런타임에 task DAG를 생성해 독립적인 작업을 병렬화하고 결과를 합성한다. Claude, ChatGPT, Gemini, DeepSeek, 로컬 모델을 백엔드로 지원.
- **검증 (5/5 통과)**

  - 신뢰도: GitHub 6.6k stars

  - 재현성: npm 패키지로 즉시 스캐폴딩 가능
  - 신규성: 2026-04-01 최초 출시, 미보고
