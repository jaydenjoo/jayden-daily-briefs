### [카테고리 1] Claude Code / Agentic SDK 패턴

#### `anthropics/claude-plugins-official` ★29.9k | 업데이트: 2026-06-11
**URL**: https://github.com/anthropics/claude-plugins-official

Anthropic이 직접 관리하는 고품질 Claude Code 플러그인 공식 디렉토리. `/plugins`(Anthropic 제작)와 `/external_plugins`(파트너·커뮤니티) 두 경로로 구성.

**플러그인 구조**:
```
plugin-name/
├── .claude-plugin/plugin.json   # 플러그인 메타데이터 (필수)
├── .mcp.json                    # MCP 서버 설정 (선택)
├── commands/                    # 슬래시 커맨드
├── agents/                      # 에이전트 정의
├── skills/                      # Skill 정의
└── README.md
```

**설치**: `/plugin install {플러그인명}@claude-plugins-official`

**Jayden 적용 가능성**: Next.js·Supabase·n8n 관련 커뮤니티 플러그인을 1줄 설치로 즉시 테스트. 커스텀 플러그인 작성 시 이 레포의 구조가 공식 레퍼런스로 활용 가능.

**검증**: 활성도 ✅ 신뢰도 ✅ 문서화 ✅ 재현성 ✅ 신규성 ✅

#### `VILA-Lab/Dive-into-Claude-Code` ★1.6k | 라이선스: CC BY-NC-SA 4.0
**URL**: https://github.com/VILA-Lab/Dive-into-Claude-Code

Claude Code v2.1.88 소스코드(~1,900 TypeScript 파일, ~512K 라인)를 체계적으로 분석한 연구 레포.

**핵심 발견 (README 직접 발췌)**:
> "Only 1.6% of Claude Code's codebase is AI decision logic. The other 98.4% is deterministic infrastructure."

**주요 분석 항목**:
- 7개 안전 레이어 + 9단계 turn 파이프라인 아키텍처

- 프로덕션 에이전트 설계 결정사항 6가지: 추론 배치, 안전 자세, context 관리, 확장성, subagent 아키텍처, 세션 지속성

**추가 인사이트 (README 직접 발췌)**:
> "Defense-in-depth fails when layers share constraints"

**Jayden 적용 가능성**: "harness가 차별화 요소, 모델이 아니다" 원칙 → CLAUDE.md·hooks 설계 투자 근거로 활용. 6가지 설계 결정사항이 Claude Code 커스터마이징 방향 설정에 직접 참조 가능.

**검증**: 활성도 ✅ 신뢰도 ✅ 문서화 ✅ 재현성 ✅ 신규성 ✅

- Builder + Validator 에이전트 팀 패턴 지원

**Jayden 적용 가능성**: 복수 Claude Code 세션을 동시에 실행할 때(예: 여러 기능 병렬 개발) 각 에이전트 상태를 대시보드에서 실시간 확인. 비개발자도 "어느 에이전트가 내 확인을 기다리는가"를 시각적으로 파악 가능.
